# README 시연 자료

2026-10-07 배포된 [나온](https://meetnaon.vercel.app)의 실제 데스크톱 화면을 촬영했습니다. 로컬 샘플 UI가 아니라 로그인 후 실제 캐릭터 생성·수정·완성과 영상 변환을 실행한 기록입니다.

| 파일 | 내용 |
| --- | --- |
| `01-dashboard.gif` | 대시보드, 최근 작업, 진행 상태 필터 |
| `02-character.gif` | 실사 옵션 선택, 후보 4장, 슬라이더 조정, AI 수정 적용, 3방향 완성 |
| `03-video.gif` | 캐릭터 선택, 원본 영상 미리보기, 실제 변환 진행 상태, 완료 및 결과 재생 |

- 데스크톱 1440×960 화면을 촬영하고, 자막을 포함한 1280×922 GIF로 편집했습니다.
- 생성 대기는 축약했으며, GIF 재생 시간은 실제 처리 시간이 아닙니다.
- 정지 화면 사이에는 0.25초 디졸브 전환을 넣었습니다. 결과 재생 구간은 동일 작업의 실제 결과 MP4를 20fps로 추출해 촬영 화면의 플레이어 영역에 배치했습니다. 재생 컨트롤은 가리고 원래 결과 영상과 속도를 유지했습니다.
- 각 GIF와 같은 이름의 PNG는 움직임 없이 확인할 수 있는 정지 화면입니다.
- 캐릭터 시연은 `나온 스튜디오`, 영상 시연은 별도로 만든 `나온 데모`를 사용했습니다.
- 영상 원본은 사용자가 테스트용으로 제공한 8.1초 MP4입니다. 원본 파일, 계정 인증 정보, 임시 signed URL은 저장소에 포함하지 않았습니다.
- 시연은 촬영 당시 배포 버전의 결과입니다. 이후 수정된 코드의 생성 품질을 검증하는 자료는 아니며, 변경 후에는 같은 시나리오로 다시 촬영해야 합니다.

교체할 때는 각 파일명을 유지하면 README 링크가 그대로 동작합니다. 화면의 버튼·수치·상태를 합성하거나 생성 결과를 다른 이미지로 바꾸지 않습니다.
