# 로고 · 파비콘

원본 가이드(영문)를 그대로 옮기고, 이 레포에서 어디에 어떻게 들어갔는지를 덧붙였다.

## 레포에 들어간 자리

| 파일 | 원본 | 쓰임 |
|---|---|---|
| `src/app/favicon.ico` | `symbol-web.png` + 크림 배경 → 16·32·48px, 둥근 모서리 | 브라우저 탭. Next가 `<link rel="icon">`을 붙인다 |
| `src/app/icon.png` | `symbol-web.png` + 크림 배경 → 192px, 둥근 모서리 | 고해상도 아이콘(안드로이드 등) |
| `src/app/apple-icon.png` | `symbol-mobile-1024.png` → 180px, 크림 배경 | iOS 홈 화면. iOS는 투명을 검게 칠해서 배경판을 깔았다 |
| `public/brand/symbol.png` | `symbol-web.png` 여백 잘라 90×120 | 화면 속 로고 — `src/components/app/BrandMark.tsx` |

화면 안에서는 **차콜 심볼만** 쓴다(사이드바 · 모바일 상단 · 로그인). 서비스 이름이 아직 없어서 글자를 붙이지 않는다.

**파비콘도 크림(`#f7f4ed`) 배경 + 차콜 심볼이다 (2026-09-17 결정).** 원본 가이드의 코발트 파비콘은 쓰지 않는다 —
앱 기본 배경색과 맞춘다. 16px에서도 형태가 보이게 작은 크기일수록 심볼을 크게 채웠다. 지금 레포에 파란색은 없다.
이름이 정해지면 이미지에 굽지 말고 `BrandMark` 옆에 글자로 더한다.

### 모서리 · 심볼 크기 (2026-09-18 결정)

파비콘 배경판의 네 모서리를 둥글게 깎고, 그 안의 심볼은 10% 줄여 여백을 넓혔다.

- **모서리 반경은 48px 기준 8px**, 즉 변의 16.7%다. 크기마다 같은 **비율**로 적용한다 — 48px→8, 32px→5, 16px→3, 192px→32.
  한 값으로 고정하면 16px 탭 아이콘이 거의 원형이 된다.
- **심볼은 이전 대비 0.9배.** 크기별로 심볼을 다르게 채운 비율(작을수록 크게)은 그대로 두고, 각자 자기 비율에서 10%씩만 줄였다.
- 모서리 바깥은 투명이다. 배경은 크림(`#f7f4ed`), 심볼은 차콜(`#1c1c1c`) 두 톤만 쓴다.
- `apple-icon.png`는 **깎지 않는다.** iOS가 자체 마스크를 씌우고 투명한 자리를 검게 칠해서, 미리 깎으면 모서리에 검은 자국이 남는다. 크림 배경판을 깐 이유와 같다.
- 다시 만들 때는 192px `icon.png`의 심볼을 원본으로 삼아 각 크기로 줄인다(작은 크기를 확대하지 않는다). 16·32px은 내려받은 뒤 중간 회색을 양끝으로 밀어 또렷하게 만든다.

# Symbol logo guide

## Concept: The Shift

The symbol is formed by two opposing planes and one open passage.

- Left plane: the current self.
- Right plane: a newly created character.
- Central opening: the passage between the two identities.
- Diagonal cuts: the moment one scene transforms into another.
- Offset balance: different identities can coexist without one erasing the other.

The mark intentionally contains no product name or initial, so it can remain in use after the service is renamed.

## Palette

- Charcoal: `#1C1C1C`
- Cream: `#F7F4ED`
- Favicon cobalt: `#3157D5`

The web mark should normally appear in charcoal on cream or white. The cobalt treatment is reserved for small identity surfaces such as the favicon, where stronger contrast improves recognition.

## Files

- `symbol-web.png`: approved main symbol with a transparent background.
- `symbol-mobile-1024.png`: 1024 px mobile/app icon on cream.
- `favicon-512.png`: high-resolution favicon source.
- `favicon-32.png`: browser-tab favicon.

## Usage notes

- Keep clear space around the mark equal to at least one quarter of its width.
- Do not stretch, rotate, outline, or add a drop shadow.
- For very small use, prefer the cobalt favicon version.
- Until a final product name is chosen, pair the symbol with UI text rather than baking a temporary name into the image.
