# 관리자 백오피스와 무통장입금 운영

## 화면

- /admin: 전체 사용자·보유 크레딧, 최근 14일 사용·수동 충전, 일별 차트와 최근 충전.
- /admin/users: 이름·이메일·ID 검색, 잔액 0 필터, 25명 단위 페이지 이동.
- /admin/users/[id]: 잔액, 누적 사용·구매·환불, 내역 필터와 수동 충전.
- /admin/topups: 입금액, 지급량, 거래 식별번호, 입금 확인·메모 뱃지와 처리 시각. 처리자 정보는 감사 기록에만 보존한다.
- /admin/settings: 요금제 최대 6개와 입금 계좌·안내 문구 설정. 초기에는 비공개.
- /credits: 공개된 요금제 선택, 계좌 복사, 입금 순서, 보유 잔액과 사용 내역.

## 권한과 충전

사용자가 확인한 sunlightsnow123@gmail.com 계정의 UUID와 이메일이 모두 일치할 때만 마이그레이션에서 관리자로 등록한다. 사용자 metadata나 클라이언트 입력으로 역할을 바꿀 수 없다. 메뉴 숨김 외에 서버 로그인 검사, Edge getUser 검증, 별도 관리자 테이블 확인, DB 함수 권한과 actor 확인을 사용한다. Vercel에는 service_role 키를 넣지 않는다.

충전은 Edge Function을 통해서만 실행한다. 요청 UUID는 재시도 중 유지하고, 은행 거래 식별번호도 고유하게 기록한다. 동일한 입금은 같은 식별번호를 사용한다. 크레딧 증가·원장·처리 기록은 하나의 DB 트랜잭션이며 실패 시 모두 취소된다. 금액과 크레딧은 양의 정수만 허용한다. 관리자 메모·입금자·은행 거래번호는 일반 사용자 원장에 포함하지 않는다.

## 사용자 삭제와 썸네일

삭제는 본인 계정만 가능한 기록 보존형(soft delete)이다. 일반 사용자의 RLS 조회에서 삭제된 항목을 숨기며 복구 UI는 제공하지 않는다. 생성 중 작업과 연관 작업이 진행 중인 캐릭터는 삭제하지 못한다. 캐릭터 삭제 후 이미 만든 영상과 크레딧 원장은 유지한다. 원본 스토리지 파일은 즉시 영구 제거하지 않는다. 운영 시 별도 보존·정리 정책을 정할 수 있다.

영상 썸네일이 없으면 캐릭터 대표 이미지를 사용하고 이를 표시한다. 이미지 로딩 실패와 이미지 없는 상태에서도 크림색 배경·상태 아이콘·영상 보기 안내를 보여준다. 생성 중 아이콘 및 hover 효과는 reduced-motion을 존중한다.

## 검증

- npm run test:db: PGlite(격리된 PostgreSQL)에서 모든 마이그레이션 적용 후 권한·원장·중복 지급·요금제 공개·본인 삭제·생성 중 보호·RLS를 검증한다. 운영 DB에 연결하지 않는다.
- npm run test:admin: 입력·금액 범위와 공개 설정 검증.
- npm run test:prompts: 기존 생성 프롬프트 회귀 검증.
- npx supabase gen types typescript --linked: 운영 스키마에서 src/types/database.ts를 재생성한다. 생성 파일은 수동 수정하지 않는다.
- npm run lint / npm run build / npx deno check supabase/functions/admin-backoffice/index.ts

## 운영 반영 순서 (사용자 승인 후)

1. 미적용 마이그레이션이 이번 2개뿐인지 확인 후 supabase db push --linked.
2. supabase gen types typescript --linked로 src/types/database.ts 갱신 후 타입·빌드 검사.
3. admin-backoffice와 삭제 필터가 추가된 draft-character, refine-character, build-character, create-look, create-video Edge Functions 배포.
4. 관리자 계정 접근과 일반 사용자 차단을 확인한 후 승인된 main 커밋·push.
5. 운영 관리 → 요금제·계좌에서 실제 값을 설정하고 공개. 사용자 결제 화면을 확인.

운영 DB·함수 배포와 main 푸시는 사용자 확인 후 진행한다. 로컬 샘플 화면은 실제 충전·삭제를 실행하지 않는다.
