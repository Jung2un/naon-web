# 생성 재시도와 진행 안내 (2026-09-20)

- 실패한 영상 상세에 `다시 시도하기`를 제공한다. 보관된 원본을 새 작업 폴더에 복사 업로드하고 기존 `create-video` 검증·차감·환불 경로를 사용한다. 룩 보류 기간에는 캐릭터 기본 이미지로 재시도한다. 버튼 옆에서 새 작업의 1크레딧 비용을 알린다.
- 원본이 없으면 버튼을 비활성화하고 영상 업로드 링크를 제공한다. 진행 중 작업에는 재시도 버튼을 제공하지 않는다.
- 같은 화면에서 접수 응답을 잃어 재시도해도 같은 작업 ID를 재사용한다. 서버의 기존 동일 ID 중복 접수 방지 규칙을 사용한다. 자동 유료 재시도는 없다.
- 캐릭터 실패 시 후보·다듬기·3방향 중 실패한 단계에 맞는 재시도 버튼과 비용을 표시한다. 다듬기 재시도는 실패한 이미지 행에 보관된 속성을 사용한다.
- 후보 생성 접수, 원본 준비/업로드, 영상 접수, 영상 대기/변환, 후보/다듬기/3방향 생성에 현재 단계와 경과 시간을 표시한다.
- 이미지 진행 막대는 실제 저장 완료 장수다. 영상에 임의의 0~100% 진행률은 표시하지 않는다. 남은 시간은 기존 안내 시간에 기반한 추정이며 보장하지 않는다. 초과 시 지연 안내로 바꾼다.
- 진행 패널이 열려 있을 때 15초마다 서버 화면을 새로 읽어 Realtime 누락을 보완한다. 이 갱신은 AI를 재호출하지 않는다.

## 검증 및 배포 상태

프로덕션 빌드와 ESLint, 로컬 서버 응답으로 실패/진행 화면 및 룩 메뉴 제거·직접 경로 이동을 확인했다. 추가 유료 생성이나 변환은 실행하지 않았다. 재시도의 실제 공급자 성공 결과는 미검증이다.

GitHub에서 이전 룩 숨김 커밋 `4a87b0c`의 Vercel 상태가 `Deployment was blocked`인 것을 확인했다. 따라서 이전 운영 화면에 룩 메뉴가 남아 있었다. Vercel 로그인이 만료되어 차단 상세 사유와 운영 재배포 확인은 계정 인증 후 필요하다. main push와 운영 배포 완료는 별개다.
