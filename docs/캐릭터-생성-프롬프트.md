# 캐릭터 후보 요청 설계 (2026-09-20)

## 목표와 기준

`public/catalog/tone/1.jpg`(실사), `4.jpg`(일상 스냅), `3.jpg`(화보), `2.jpg`(시네마틱)을 직접 확인하고, 부드러운 얼굴 조명·맑은 피부 표현·단정한 한국 배우 프로필 같은 인상을 요청에 반영했다. 기존의 짧은 키워드와 일괄적인 `plain neutral background` 지시를 구체적인 장면 설명으로 바꿨다.

이 변경은 **텍스트 요청 개선**이다. 썸네일 파일 자체를 Gemini에 첨부하거나 같은 얼굴을 복제하는 변경은 아니다. 원하는 미감을 설명하되 새로운 가상 성인 캐릭터를 생성한다. 실제 개선 정도는 동일 옵션의 후속 이미지 비교가 필요하며, 이번 코드 검증에서는 유료 생성을 실행하지 않는다.

## 요청 구조

`draftPrompt()`가 아래 순서로 조립하고, 기존 Gemini `input`의 text로 전송한다. 네거티브 프롬프트용 별도 API 필드나 Midjourney 전용 옵션을 추가하지 않는다.

1. **목적:** 프리미엄 캐릭터 카탈로그용 한국 성인 인물, 배우 프로필·정돈된 라이프스타일 사진의 미감.
2. **필수 속성:** DB에서 선택한 성별, 나이, 머리, 머리색, 체형, 분위기. 미적 지시보다 사용자 선택이 우선한다.
3. **나이:** 20대만 생기·편안한 눈가·부드러운 얼굴 볼륨을 강조한다. 30·40·50대는 해당 나이의 특징을 유지하고 조명과 스타일링으로 표현을 다듬는다.
4. **매체·조명·배경:** `character_options.prompt`에서 선택한 톤의 설명을 가져온다.
5. **후보 차이:** 후보별 얼굴 윤곽을 부드러운 타원형·살짝 좁아지는 형태·둥근 형태·각진 형태로 다르게 지시한다. 성별·나이·머리 등의 선택은 바꾸지 않는다.
6. **구도:** 3:4 상반신, 눈높이, 머리 전체와 양어깨 포함, 두 눈과 얼굴 윤곽이 보이는 거의 정면. 배경은 톤에 맞게 단순화한다.
7. **마감·제외:** 자연스러운 비대칭과 인상 유지, 눈 선명도, 단정한 스타일링. 선택한 매체에 맞는 얼굴 비율을 유지하고 의도치 않은 왜곡·과도한 샤프닝·콜라주·문자 등을 피한다.

## 톤별 차이

| 톤 | 핵심 요청 |
|---|---|
| 실사 | 확산된 창가 빛, 눈가의 약한 보조광, 작은 캐치라이트, 베이지 실내, 50mm 느낌, 섬세한 피부 질감 |
| 일상 스냅 | 조용한 카페 밖, 따뜻한 역광과 얼굴을 밝히는 반사광, 캐주얼 복장, 편안한 자세, 자연스러운 스마트폰 원근감 |
| 화보 | 밝은 회색 스튜디오, 큰 소프트박스와 보조광, 85mm 느낌, 절제된 뷰티 보정, 선명한 눈 |
| 시네마틱 | 블루아워 창가·도시 보케, 청색 주변광·따뜻한 가장자리 빛, 얼굴이 묻히지 않는 보조광, 은은한 그레인 |

애니와 3D의 DB 프롬프트는 바꾸지 않는다. 공통 요청에서 사진용 모공·렌즈·피부 보정을 강제하지 않는다. 다듬기·3방향에서는 새 인물을 캐스팅하는 지시를 재사용하지 않고 기존 얼굴 유지 프롬프트를 계속 사용한다.

## 실사 요청의 핵심 예

```text
Create one original fictional Korean adult character for a premium character casting catalog.
Required choices: a woman, in their early twenties, layered medium-length hair, black hair.
The person must visibly read as an adult in their early twenties, with rested eyes and soft facial volume.
A polished photorealistic Korean lifestyle portrait. Soft diffused window daylight wraps around the face,
with gentle fill in the eye sockets and small natural catchlights. A warm beige interior falls softly out of focus.
Skin looks clear and luminous, with fine believable texture and restrained beauty retouching.
A vertical 3:4 upper-body portrait at eye level, complete head and both shoulders visible.
Keep the face nearly forward, unobstructed and sharply readable. One original person, no collage or text.
```

실제 요청은 선택한 DB 속성과 톤 전체 설명을 포함한다. 위 예문의 나이·성별·머리를 모든 요청에 고정하지 않는다.

## 검증과 운영 반영

`npm run test:prompts`는 네트워크나 API 키 없이 실제 프롬프트 조립과 마이그레이션의 톤 문장을 검증한다. 톤별 배경 보존, 나이·성별·선택 속성 보존, 애니/3D 분리, 네 후보 차이, 편집 시 동일 인물 유지 계약을 확인한다. 이미지 품질 자체를 보장하는 테스트는 아니다.

**Git main push만으로 Supabase 코드와 DB는 바뀌지 않는다.** 운영에는 아래 순서가 필요하다.

```sh
npx supabase db push --linked
npx supabase functions deploy draft-character --project-ref alafyhejiaxukrkrmehh
```

마이그레이션 `20260920000001_portrait_tone_prompts.sql`은 기존 네 톤의 prompt만 갱신한다. 스키마·과금·모델·해상도·생성 장수는 바꾸지 않는다. 두 단계 적용 후 새로 뽑은 후보부터 새 요청을 사용하며, 이미 생성한 이미지는 그대로 남는다.

공식 참고: [Gemini 이미지 생성 프롬프트 가이드](https://ai.google.dev/gemini-api/docs/image-generation). 키워드 나열보다 장면을 서술하고, 원하는 구도·조명·질감을 구체적으로 지정하는 원칙을 적용했다.
