# 룩 / 배경 UI 보관

2026-09-20 사용자 요청으로 임시 비활성화했다. 큰 JSX 블록을 주석으로 지우는 대신 원본을 이 폴더로 이동하고 `config.ts`의 공통 설정을 `false`로 두었다. 활성화용 `true` 선언은 그 파일에 주석으로 남겼다.

- `LooksPage.tsx`: 기존 룩 목록 페이지
- `NewLookPage.tsx`: 기존 룩 생성 페이지
- `LookBuilder.tsx`: 의상 및 배경(장소) 선택과 생성
- `LookCard.tsx`, `SummaryBar.tsx`: 룩 전용 표시 컴포넌트
- `config.ts`: 메뉴·안내·상세·영상 선택·페이지 접근을 함께 제어하는 설정

꺼진 동안 메뉴와 홈 안내의 룩 진입, 캐릭터 상세의 룩 목록/버튼/개수, 영상 생성의 스타일 선택, 작업 상세의 룩 행을 숨긴다. `/looks`, `/looks/new`는 데이터 조회나 생성 없이 `/characters`로 이동한다. 영상 생성 요청은 `look_id: null`로 보내 캐릭터 기본 이미지를 사용한다.

복원: `LOOKS_ENABLED`를 `true`로 바꾼 뒤 웹을 빌드·배포한다. 라우트의 얇은 연결 파일은 원래 위치에 유지해 URL을 보존했다.

DB 테이블·기존 생성물·카탈로그 이미지·Supabase `create-look` API는 보존한다. 이는 웹 UI를 보류하는 변경이며 서버 API 권한을 차단하는 변경은 아니다. 공유 조회/타입과 캐릭터 톤에 사용되는 배경 프롬프트도 유지한다.
